Dissertation Project | Graded - 1st class

This project's aim is to increase engagement in education with children in primary education through a mobile game, using extended reality features. The game involves unlocking a in-game character via scanning an NFC tag attached to a 3D printed character. 
The user can then earn stars to level their character through partaking in quizes containing questions set by their teachers, stored in an SQLite database. Once the characters are levelled the user can take the character into three mini-games where the higher their level the higher possible score.

Tech Stack:

-NFC scannable 3D printed characters for toys to life feature.

-Unity developed mobile game using C#, Java and Objective-C.

-3D models and animations using Blender.

-Object pooling for enemy, particle and item spawning for increased performance and garbage collection.

-Java and Objective-C plugin for mobile NFC read and write system.

-Json implementation for saving character level, stat and score data.

-SQLite database for question storage.
